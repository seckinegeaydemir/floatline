# Changelog

## 1.0.0

First public release.

- Safari Web Extension packaged in a signed macOS menu bar app, so the extension stays enabled across Safari restarts.
- One-click native Picture in Picture for HTML5 video.
- Automatic caption mirroring into the PiP window, placed above the PiP control bar.
- Caption size setting (50–150 %) with a live preview.
- English and Turkish; defaults to the Mac's language.
- Experimental skip-intro control in PiP on supported services.
